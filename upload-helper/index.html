QUICK GUIDE

Where does everything go?

  1. Import all 3 ZIPs here.

    The helper opens them locally. You do not upload the ZIPs themselves to iGEM.

  2. Images & files → iGEM Uploads

    Open it from step 2 and sign in. Return here and click “Upload / check remaining files”. The helper organizes files into folders and saves their official links.

  3. Video & audio → Video Universe

    Only needed for recordings. Sign in there, run an upload pass, then finish that recording’s details and captions. Repeat for the next recording. Check moderation before publishing.

  4. Website code → iGEM GitLab

    After media links are saved, open GitLab and sign in. Check the source changes in step 3 and send them for review. Open the merge request and merge it when ready. Check the resulting build and wiki.

Paused, stuck or continuing later?

Read Current status first. Keep the helper terminal open. Pause preserves completed uploads. Use “Upload / check remaining files” to check a pending file without sending it twice. If iGEM explicitly rejected a file, open Files & upload status and use its retry button.

To continue another day, keep the helper’s jobs folder and choose “Continue an earlier upload”. Sign in again in the helper’s browser.
